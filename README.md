# AssetView

개인 자산을 한 화면에서 정리하고, 월별 변화와 자산배분 상태를 확인하기 위한 **단일 HTML 기반 자산관리 도구**입니다.

GitHub Pages에 `index.html`을 올리면 별도 서버 없이 웹브라우저에서 사용할 수 있습니다.

## 주요 기능

- 대시보드
  - 현재 총자산
  - 상품유형별 / 자산군별 비중
  - 월별 자산 추이
  - 큰 자산
  - 최근 변동메모
  - 시장 신호
  - 내 포트폴리오 상태

- 자산 관리
  - 주식, ETF, 현금, 예적금, 부동산, 연금 등 등록
  - 계좌별 / 상품유형별 / 자산군별 관리
  - 태그, 소유자, 매입원금 등 관리

- 계좌 관리
  - 금융사·계좌유형별 관리
  - 이체 기록 확인

- 추이
  - 총자산 추이
  - 상품유형별 추이
  - 자산군별 추이
  - 개별 자산 추이
  - 월별 자산 증감 비교

- 변동메모
  - 매수 / 매도 / 입금 / 출금 / 이체 / 조정 기록
  - 월별 변동원인 기록
  - 자산별 변동 기여 분석
  - 변동메모는 **원본 자산 금액이나 수량을 자동 변경하지 않는 참고·분석용 기록**

- 월말 기록
  - 자산별 월말 스냅샷 저장
  - 과거 평가금액·수량 수정
  - 월별 자산 변화 추적

- 시장 신호
  - S&P500 200일선 상회 종목 비율
  - RSP/SPY 최근 4주 상대추세
  - 미국 10년물 국채수익률
  - Nasdaq-100 최근 52주 고점 대비 등락률
  - 시장진단 및 현재 행동 기록

- 포트폴리오 상태
  - 성장주 노출
  - 현금성 비중
  - 단일종목 집중도
  - 추가 성장주 매수 여력

- 데이터 관리
  - JSON 불러오기 / 내보내기
  - CSV 내보내기

## 사용 방법

### 1. 웹에서 실행

GitHub Pages를 사용하는 경우 저장소 루트에 `index.html`을 두고 Pages를 활성화하면 됩니다.

예시:

```text
https://<GitHub아이디>.github.io/assetview/
```

### 2. 자산 데이터 불러오기

처음 실행하면 자산 데이터는 비어 있습니다.

상단의 **JSON 불러오기** 버튼을 눌러 기존 AssetView JSON 파일을 불러오세요.

### 3. 월말 업데이트 권장 흐름

1. 월말 기준으로 자산 정보를 업데이트
2. `월말 기록` 저장
3. JSON 내보내기
4. 다음 달 초 시장신호 업데이트
5. 필요하면 JSON을 ChatGPT에 첨부하여 시장상황과 포트폴리오 상태를 함께 점검

## 데이터 저장 방식

AssetView의 데이터는 기본적으로 **브라우저의 localStorage**에 저장됩니다.

따라서:

- 같은 기기·같은 브라우저에서는 자동으로 유지됩니다.
- 다른 PC나 휴대폰에서는 자동 동기화되지 않습니다.
- 다른 기기에서 사용하려면 JSON 파일을 다시 불러와야 합니다.

### 중요

GitHub 저장소가 Public이라면 **개인 자산 JSON 파일을 저장소에 올리지 마세요.**

`index.html`만 공개하고, 실제 자산 데이터는 각 기기에서 직접 JSON으로 불러오는 방식을 권장합니다.

## GitHub Pages 배포

1. GitHub 저장소 생성
2. `index.html` 업로드
3. `Settings → Pages`
4. Source: `Deploy from a branch`
5. Branch: `main`
6. Folder: `/(root)`
7. Save

잠시 후 Pages 주소가 생성됩니다.

## 파일 구성

```text
/
├─ index.html
└─ README.md
```

현재 버전은 별도 빌드 과정이나 외부 프레임워크 없이 `index.html` 하나로 실행됩니다.

## 주의사항

- 본 도구는 개인 자산관리 및 기록용입니다.
- 시장신호와 포트폴리오 상태는 참고용이며 투자수익을 보장하지 않습니다.
- 시장신호는 월 1회 정도 업데이트하는 용도로 설계했습니다.
- 실제 투자 판단 시에는 자신의 투자기간, 현금흐름, 세금, 손실 감내 수준 등을 함께 고려하세요.

## 권장 사용 방식

AssetView는 단기 매매 신호보다는 다음과 같은 용도에 적합합니다.

- 월말 자산현황 기록
- 자산배분 점검
- 특정 종목 집중도 확인
- 현금성 자산 비중 관리
- 월별 변화 원인 기록
- 시장환경과 내 포트폴리오 상태를 함께 점검
